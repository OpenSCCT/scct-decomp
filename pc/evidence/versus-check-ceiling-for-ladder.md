# Versus CheckCeilingForLadder compiler evidence

Steam build 252084 registers SBase.SPlayerController.CheckCeilingForLadder as native 1786. Its complete x86 body occupies file offsets `[0x1a3a40,0x1a3af8)` in the locked Versus image. The shipped editor names the same function and shows the time constructor for its result, both zero vectors and the same trace arguments. Editor SHA-256 is `3139b5dcc9f5e531a4109c622196e1ae00234f41904d0ab6ee4b53670c0a68d4`. The editor native starts at VA `0x111e44c0` and calls the named level trace at `0x111e459f`.

Microsoft C/C++ 13.00.9466 for x86, using `/O2 /Gy /GL` and its 7.00.9466 LTCG linker, rebuilds all 184 bytes with the level trace implementation visible. The two source files produce the same normalized retail bytes when compiled separately into whole-program objects and when compiled through the replay driver. Both methods have direct callers in the retail game. The driver includes the actual two methods. The link uses each method's entry as a root. Separate-object and driver builds give SHA-256 `0b10c9bf69ed9d71f2bbe662de04800c97fbce94dcb5d40e8bbca8e2efd59fb7` for the placed caller. The same driver and flags under Toolkit 2003 13.10.3052 produce 192 bytes. With only the declaration of the trace visible, 13.00.9466 produces 261 bytes.

Retail calls `ULevel::SingleLineCheck` at VA `0x10aa3ad5`. Its output path copies fourteen dwords on a hit and writes Time and Actor on a miss. This lets the period optimizer discard the unused constructor stores in the caller. The caller's three code operands bind the 64.0f literal at `0x10c10cc0`, the trace entry at `0x10a1d200` and the 1.0f literal at `0x10c109fc`. Each constant is verified against the corresponding retail bytes. The receipt covers the caller. The trace implementation is a source dependency with no separate match claim.

The trace's stack mark, level model and actor list are visible in the retail function at file offsets `[0x11d200,0x11d3f8)`. It copies the output, skips flagged BSP surfaces and dispatches the actor event for a nonzero word at result offset `0x34`. Game VA `0x10a1dbcd` supplies hardcoded name 0x9e7 to the event lookup. Registration at `0x1092ade6` references the string `BulletWentTru`. Stock Engine.u gives the event's four parameters. The shipped editor's named trace at `0x110be450` calls the named MultiLineCheck at `0x110be4e4`. Its conventional call passes Mem, End by value, Start, Extent, LevelInfo, flags and source actor.
